# Data Cleaner
This project takes in a "dirty" .csv file and cleans it up by getting rid of invalid entries and then redisplaying a small piece of the cleaned .csv that is then saved to a clean path.

# How to run
```
python3 src/data_cleaning.py
or
python src/data_cleaning.py
```
